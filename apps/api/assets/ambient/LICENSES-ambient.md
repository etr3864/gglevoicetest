## Processing Applied
- Trimmed to 25-45 second loops
- Normalized to -28 LUFS with -6dB true peak ceiling
- Crossfade (100ms) at loop boundaries
- Converted to: mono, 16-bit signed little-endian PCM, 24000 Hz
